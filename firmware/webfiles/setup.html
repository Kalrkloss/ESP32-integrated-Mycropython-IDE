1. Network

The board is not configured yet, so it opened this open access point. Enter the WiFi it should join; after a restart it connects there and this page is reachable at its normal address. If it cannot connect, it re-opens the access point.

2. Board

Only boards whose ESP32 type matches this firmware are listed: a firmware image is built for exactly one chip.

3. Display and touch

Values from the profile are pre-filled. Wrong pins can put the panel into boot mode -- if it stays dark, open this page again and correct them (the access point comes up before the display is touched).
